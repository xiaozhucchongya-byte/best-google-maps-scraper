# Google Place ID

A Google Place ID is a unique identifier for every business listed on Google Maps.

CoreClaw supports:

- Extracting Google Place IDs
- Searching by Place ID
- Batch Place ID processing

## Use Cases

- Business Deduplication
- Database Matching
- CRM Integration
- Local SEO
